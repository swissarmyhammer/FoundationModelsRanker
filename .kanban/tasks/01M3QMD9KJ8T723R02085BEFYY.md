title: Remove dimension from TextEmbedding

## What
An embedder that loads its model at the first call cannot know its dimension before that call. Each vector carries its own length, so the protocol does not need it.

```swift
public protocol TextEmbedding: Sendable {
    func embed(_ texts: [String]) async throws -> [[Float]]
}
```

- `Sources/FoundationModelsRanker/TextEmbedding.swift`: remove `var dimension: Int { get }` and the doc lines about it.
- Each Ranker source that reads `dimension` from an embedder reads the length of a returned vector in its place (`CosineScoring` keeps its own `dimension:` parameter, which is a matrix width, not the protocol).
- `Examples/FullMontyCore/DemoEmbedder.swift` and `README.md`: remove `dimension`.
- Remove `dimension` from each Ranker test double.
- Push to `origin main` when green.
